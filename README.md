# K49.SPTIN.B-SPNC-KhuonHD

Website hỗ trợ học sinh lớp 6 học Tin học theo hướng thân thiện, trực quan và dễ thao tác.

## Mục tiêu

- Trang chủ giới thiệu dự án và điều hướng đến các công cụ học tập.
- Từ điển thuật ngữ giúp tra cứu nhanh khái niệm Tin học.
- Trò chơi ô chữ tăng tính ghi nhớ và tương tác.
- Mô phỏng thuật toán làm kem giúp hiểu sơ đồ khối và cấu trúc rẽ nhánh.

## Cấu trúc file

- `index.html`: trang chủ.
- `dictionary.html`: từ điển thuật ngữ Tin học.
- `crossword.html`: trò chơi giải ô chữ Thư điện tử.
- `algorithm.html`: mô phỏng thuật toán làm kem.
- `assets/css/style.css`: kiểu giao diện dùng chung.
- `assets/js/main.js`: hiệu ứng cho trang chủ.
- `assets/js/dictionary.js`: logic từ điển.
- `assets/js/crossword.js`: logic trò chơi ô chữ.
- `assets/js/algorithm.js`: logic mô phỏng sơ đồ khối.

## Cách chạy

Mở trực tiếp `index.html` bằng trình duyệt hoặc triển khai lên GitHub Pages.

## Lưu ý khi deploy lên GitHub Pages

- Nếu vừa cập nhật CSS hoặc JS mà giao diện chưa đổi, hãy hard refresh trình duyệt.
- Dự án hiện dùng cache-busting cho file CSS với tham số phiên bản để giảm lỗi cache trên GitHub Pages.
